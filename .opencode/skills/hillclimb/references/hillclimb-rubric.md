# Hillclimb rubric (moved)

This path is kept so older links keep working. The perception rubric now lives at
[`rubrics/perception.md`](rubrics/perception.md), alongside `usability`,
`performance` and `completeness`.

The hillclimb skill selects a rubric per run — an explicit `Rubric: <name>` wins,
otherwise the seam's `rubrics.default`, otherwise `perception`. Read the selected
file in `references/rubrics/`, not this pointer.

Nothing in this file is a gate. If a document or an agent quotes this path, follow
the pointer and quote the selected rubric instead.
